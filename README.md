# 5 pequenos projetos com HTML, CSS e JavaScript

Repositório com cinco projetos para praticar os fundamentos de desenvolvimento web. Cada projeto tem sua própria pasta e contém `index.html`, `style.css` e `script.js`.

## Projetos

1. **Cartão de Apresentação** — estrutura HTML, estilos CSS e evento de clique.
2. **Gerador de Frases** — arrays, números aleatórios e atualização do conteúdo da página.
3. **Calculadora de Média** — formulários, conversão de valores e condicionais.
4. **Lista de Tarefas** — manipulação do DOM, criação e remoção de elementos e classes CSS.
5. **Quiz de Disciplina** — array de objetos, eventos, pontuação, progresso e tela final.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto desejado.
3. Abra o arquivo `index.html` no navegador.
4. Para editar o código, abra a pasta no Visual Studio Code.

Não é necessário instalar dependências ou usar um servidor.
